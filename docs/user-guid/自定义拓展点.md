# 自定义拓展点

------

## 1. 什么是拓展点

拓展点（ExtensionPoint）是插件系统中允许自定义功能的正式声明位置，是平台能力与插件实现之间的契约边界。

------

## 2. 定义拓展点

### 2.1 创建拓展点接口

拓展点接口必须继承 `ExtensionPoint` 标记接口：

```java
public interface MyService extends ExtensionPoint {
    String process(String input);
}
```

### 2.2 拓展点设计原则

- 接口职责单一，避免聚合多种语义
- 接口设计应稳定，避免频繁变更
- 参数和返回值应使用标准类型或DTO

------

## 3. 实现拓展点

### 3.1 使用 @Extension 注解

```java
@Extension(points = MyService.class, priority = 100)
public class MyServiceImpl implements MyService {
    @Override
    public String process(String input) {
        return "Processed: " + input;
    }
}
```

### 3.2 @Extension 注解属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| points | 显式声明实现的扩展点接口 | 自动推断 |
| priority | 优先级，值越大优先级越高 | 0 |
| enabled | 是否启用该扩展实现 | true |
| name | 扩展名称，用于UI展示 | 空字符串 |
| description | 扩展描述 | 空字符串 |

### 3.3 优先级策略

| 场景 | 优先级建议 | 说明 |
|------|-----------|------|
| 默认实现 | 50 | 中等优先级 |
| 覆盖实现 | 100 | 高优先级，覆盖默认行为 |
| 兜底实现 | 0-25 | 低优先级，作为备选 |
| 测试实现 | 200 | 最高优先级，用于测试覆盖 |

------

## 4. 注册拓展点实现

### 4.1 在插件中注册

```java
public class MyPlugin extends AbstractPlugin {

    @Override
    protected void start() throws Exception {
        // 注册扩展点实现
        extensions().register(MyService.class, new MyServiceImpl(), 100);
    }

    @Override
    protected void stop() throws Exception {
        // 扩展会自动注销，无需手动处理
    }
}
```

### 4.2 使用注解自动发现

编译期通过 `ExtensionAnnotationProcessor` 扫描 `@Extension` 注解，生成扩展索引文件，运行期自动加载。

------

## 5. 使用拓展点

### 5.1 获取单个实现

```java
Optional<MyService> service = extensionRegistry.get(MyService.class);
service.ifPresent(s -> System.out.println(s.process("input")));
```

### 5.2 获取所有实现

```java
List<MyService> services = extensionRegistry.getAll(MyService.class);
for (MyService s : services) {
    System.out.println(s.process("input"));
}
```

### 5.3 多实现优先级

当同一扩展点存在多个实现时，系统按优先级选择：

```java
// 注册多个实现
extensionRegistry.register(MyService.class, defaultImpl, 50);
extensionRegistry.register(MyService.class, overrideImpl, 100);

// 获取最高优先级实现（返回 overrideImpl）
Optional<MyService> service = extensionRegistry.get(MyService.class);
```

### 5.4 高频访问优化（ExtensionConsumer）

对于高频访问的扩展点，直接使用 `ExtensionRegistry` 每次都会触发解析和排序。推荐使用 `ExtensionConsumer` 模板，它提供**缓存 + 事件驱动失效**的能力：

```java
// 创建消费者（通常在配置类中作为 Bean 声明）
ExtensionConsumer<MyService> consumer = new ExtensionConsumer<>(
    MyService.class, extensionRegistry, eventBus);

// 获取最高优先级实现（返回缓存结果）
Optional<MyService> best = consumer.get();

// 获取所有实现（按优先级降序，返回缓存结果）
List<MyService> all = consumer.getAll();
```

**优势**：

- 首次访问后缓存结果，后续读取直接返回缓存
- 自动订阅 `ExtensionChangedEvent`，当关联扩展点发生注册/注销/清空时自动失效缓存
- 缓存使用双重检查锁定，保证线程安全

## 6. 完整示例

### 6.1 定义拓展点

```java
public interface DataProcessor extends ExtensionPoint {
    byte[] process(byte[] data);
    boolean supports(String format);
}
```

### 6.2 实现拓展点

```java
@Extension(points = DataProcessor.class, priority = 100, name = "JSON处理器")
public class JsonProcessor implements DataProcessor {
    @Override
    public byte[] process(byte[] data) {
        // JSON处理逻辑
        return data;
    }
    
    @Override
    public boolean supports(String format) {
        return "json".equalsIgnoreCase(format);
    }
}
```

### 6.3 在插件中注册

```java
public class DataPlugin extends AbstractPlugin {

    @Override
    protected void start() throws Exception {
        extensions().register(DataProcessor.class, new JsonProcessor(), 100);
    }
}
```
