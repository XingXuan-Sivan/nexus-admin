# 使用事件总线

------

## 1. 订阅事件

### 1.1 基本订阅

```java
eventBus.subscribe(PluginStateChangedEvent.class, event -> {
    System.out.println("插件 " + event.plugin().getPluginId() + 
                       " 状态变更: " + event.from() + " -> " + event.to());
});
```

### 1.2 监听特定状态

```java
eventBus.subscribe(PluginStateChangedEvent.class, event -> {
    if (event.isEntering(PluginState.ACTIVE)) {
        System.out.println("插件 " + event.plugin().getPluginId() + " 已启动");
    }
});
```

### 1.3 监听批处理阶段

```java
eventBus.subscribe(PluginProcessEvent.class, event -> {
    if (event.phase() == PluginProcessEvent.Phase.LOAD && 
        event.stage() == PluginProcessEvent.Stage.END) {
        System.out.println("加载完成，共 " + event.count() + " 个插件");
    }
});
```

## 2. 发布事件

### 2.1 发布自定义事件

```java
// 定义自定义事件
public class MyCustomEvent extends Event {
    private final String message;
    
    public MyCustomEvent(String message) {
        this.message = message;
    }
    
    public String getMessage() {
        return message;
    }
}

// 发布事件
eventBus.publish(new MyCustomEvent("Hello World"));
```

### 2.2 在插件中发布事件

```java
public class MyPlugin implements Plugin {
    private EventPublisher eventPublisher;
    
    @Override
    public void onInitialize(PluginContext context) throws Exception {
        this.eventPublisher = context.eventPublisher();
    }
    
    @Override
    public void onStart() throws Exception {
        // 业务逻辑中发布事件
        eventPublisher.publish(new MyCustomEvent("插件启动完成"));
    }
}
```

## 3. 注销监听器

```java
// 创建监听器引用
EventListener<PluginStateChangedEvent> listener = event -> {
    // 处理逻辑
};

// 订阅
eventBus.subscribe(PluginStateChangedEvent.class, listener);

// 注销
eventBus.unsubscribe(listener);
```

## 4. 常见使用场景

### 4.1 日志记录

```java
eventBus.subscribe(PluginStateChangedEvent.class, event -> {
    logger.info("Plugin {} state changed: {} -> {}", 
        event.plugin().getPluginId(), event.from(), event.to());
});
```

### 4.2 监控告警

```java
eventBus.subscribe(PluginFailureEvent.class, event -> {
    alertService.sendAlert("Plugin failed: " + event.pluginId(), event.exception());
});
```

### 4.3 审计追踪

```java
eventBus.subscribe(PluginStateChangedEvent.class, event -> {
    auditLog.record(event.plugin().getPluginId(), 
        "STATE_CHANGE", event.from() + " -> " + event.to());
});
```

------

## 5. 注意事项

- 监听器应快速处理事件，避免阻塞事件总线
- 耗时操作应异步执行或使用独立线程
- 插件卸载时会自动清理其订阅的监听器
- 支持手动注销监听器，避免内存泄漏
