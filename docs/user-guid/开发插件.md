# 开发插件

------

## 1. 创建插件模块

在 `pom.xml` 中添加 Core（必选）与 API（可选）模块的依赖：

```xml
<dependency>
    <groupId>com.nexusadmin</groupId>
    <artifactId>nexus-admin-core</artifactId>
    <version>${project.version}</version>
</dependency>
<dependency>
    <groupId>com.nexusadmin</groupId>
    <artifactId>nexus-admin-api</artifactId>
    <version>${project.version}</version>
</dependency>
```

------

## 2. 实现插件主类

创建插件主类，继承 `AbstractPlugin` 抽象基类：

```java
public class MyPlugin extends AbstractPlugin {

    @Override
    protected void initialize() throws Exception {
        // 初始化配置
    }

    @Override
    protected void start() throws Exception {
        // 注册扩展点实现
        extensions().register(MyExtension.class, new MyExtensionImpl());
    }

    @Override
    protected void stop() throws Exception {
        // 清理资源
    }

    @Override
    protected void unload() throws Exception {
        // 卸载清理
    }
}
```

------

## 3. 创建 plugin.json

在 `src/main/resources/META-INF/` 下创建 `plugin.json`：

```json
{
  "id": "my-plugin",
  "version": "1.0.0",
  "mainClass": "com.example.MyPlugin"
}
```

------

## 4. 实现扩展点

在插件中实现扩展点：

```java
@Extension(points = MyExtension.class, priority = 100)
public class MyExtensionImpl implements MyExtension {
    @Override
    public void doSomething() {
        // 实现逻辑
    }
}
```

详见 [自定义拓展点](自定义拓展点.md) 了解如何定义和使用扩展点。

------

## 5. 插件生命周期

插件生命周期状态流转：

```
DISCOVERED → RESOLVED → LOADED → INITIALIZED → STARTING → ACTIVE
                                                  ↓
STOPPED → UNLOADED ← STOPPING ← ACTIVE
```

| 状态 | 说明 |
|------|------|
| DISCOVERED | 已发现（仅元数据） |
| RESOLVED | 依赖解析完成 |
| LOADED | 类加载完成 |
| INITIALIZED | 已初始化 |
| STARTING | 启动中 |
| ACTIVE | 运行中 |
| STOPPING | 停止中 |
| STOPPED | 已停止 |
| UNLOADED | 已卸载 |
