# 开发插件

------

## 1. 创建插件模块

在 `pom.xml` 中添加 Core（必选）与 API（可选）模块的依赖：

```xml
<dependency>
    <groupId>com.nexusadmin</groupId>
    <artifactId>nexus-admin-core</artifactId>
    <version>${project.version}</version>
</dependency>
<dependency>
    <groupId>com.nexusadmin</groupId>
    <artifactId>nexus-admin-api</artifactId>
    <version>${project.version}</version>
</dependency>
```

------

## 2. 实现 Plugin 接口

创建插件主类，实现 `Plugin` 接口：

```java
public class MyPlugin implements Plugin {
    
    @Override
    public void onInitialize(PluginContext context) throws Exception {
        // 初始化配置
    }
    
    @Override
    public void onStart() throws Exception {
        // 注册扩展点实现
        context.extensionRegistry().register(MyExtension.class, new MyExtensionImpl());
    }
    
    @Override
    public void onStop() throws Exception {
        // 清理资源
    }
    
    @Override
    public void onUnload() throws Exception {
        // 卸载清理
    }
}
```

------

## 3. 创建 plugin.json

在 `src/main/resources/META-INF/` 下创建 `plugin.json`：

```json
{
  "id": "my-plugin",
  "version": "1.0.0",
  "mainClass": "com.example.MyPlugin"
}
```

------

## 4. 实现扩展点

### 4.1 定义扩展点接口

```java
public interface MyExtension extends ExtensionPoint {
    void doSomething();
}
```

### 4.2 实现扩展点

```java
@Extension(points = MyExtension.class, priority = 100)
public class MyExtensionImpl implements MyExtension {
    @Override
    public void doSomething() {
        // 实现逻辑
    }
}
```

------

## 5. 插件生命周期

插件生命周期状态流转：

```
DISCOVERED → RESOLVED → LOADED → INITIALIZED → STARTING → ACTIVE
                                                  ↓
STOPPED → UNLOADED ← STOPPING ← ACTIVE
```

| 状态 | 说明 |
|------|------|
| DISCOVERED | 已发现（仅元数据） |
| RESOLVED | 依赖解析完成 |
| LOADED | 类加载完成 |
| INITIALIZED | 已初始化 |
| STARTING | 启动中 |
| ACTIVE | 运行中 |
| STOPPING | 停止中 |
| STOPPED | 已停止 |
| UNLOADED | 已卸载 |
